# 人类速查（不给 AI 也能核对）

1. 打开 https://bscscan.com/address/0x4a144D1A5Ca9C8e60A93C9836DD8740eB216FF5C  
2. Connect 钱包 → **Write Contract** 前先在 **Read** 看 `remaining()` > 0、`finalized()` false、`agentOf(你的地址)` 第二个值为 true。  
3. 在 USDT 合约对 Mint 地址 **Approve 1 USDT**。  
4. 回到 Mint 合约 **Write → mint()** 提交。  
5. 在 **Events** 或自己的交易里看 `Minted` 的 tier。

Registry `0x60B92…` 只用于 Agent 资格，没有 `mint()` 买卡功能。
